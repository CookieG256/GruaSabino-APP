# Grúas Sabino

Aplicativo Android/iOS da Grúas Sabino, feito com HTML, Tailwind CSS e Capacitor. O app inclui os arquivos web localmente para abrir a interface sem internet; chamadas e WhatsApp precisam de conexão.

## Baixar no Android

Baixe o APK de lançamento na página de [releases](https://github.com/CookieG256/GruaSabino-APP/releases/latest). No Android, abra o APK baixado e autorize a instalação quando solicitado.

Veja a [política de privacidade](https://cookieg256.github.io/GruaSabino-APP/privacy.html).

## Código-fonte

O projeto Capacitor está em [`GS APP/`](./GS%20APP/). Consulte o [checklist da Play Store](./GS%20APP/README-PLAY-STORE.md) para os passos restantes.

## Privacidade e assinatura

Este repositório é público. Arquivos privados, senhas e chaves de assinatura não devem ser enviados ao Git. A pasta local `GS APP/private/` e os arquivos de assinatura são ignorados. Qualquer informação incorporada ao site ou ao pacote do aplicativo pode ser vista por quem o acessa/instala; não use o app para armazenar segredos.
